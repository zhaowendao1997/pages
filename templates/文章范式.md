# 文章范式

> 这是速查表，不是要发布的文章。写新文章时，把下面「空白模板」复制到 `content/posts/`。

## 空白模板

```markdown
---
title: 标题
date: 2026-11-16
type: essay
category: 随笔
tags: [随笔]
cover: /images/covers/your-cover.jpg
summary: 一句话摘要，会显示在列表、搜索和分享卡片里。
---

第一段。

## 小标题

第二段。

![图注](/images/posts/your-photo.jpg)
```

## 文件与网址

- 文章放在 `content/posts/`，文件名就是网址：`my-post.md` → `/posts/my-post/`
- 建议用英文或拼音文件名，别带空格；中文也能用，但网址里会变成编码
- 发布后尽量不要改文件名，否则旧链接会失效

## 换行和分段

- **直接按一次回车**：同一段里换行，页面上会断成两行
- **空一行**：开始新段落，段落之间会有间距
- 不要为了排版手动在行尾加空格；直接回车就行

## 首行缩进

在段落最前面加 `[indent]`，后面留一个空格：

```markdown
[indent] 这一段的第一行会缩进两个字符。
```

- `[indent]` 本身不会显示，只控制这一段的**第一行**
- 每一段想缩进，就在每一段开头各加一个
- 也可以写成 `[indent]` 后直接换行，再写正文

## 字符格式

```markdown
**粗体**
*斜体*
~~删除线~~
`行内代码`
[链接文字](https://example.com)
```

- 外部链接会自动新窗口打开
- 不要直接贴裸网址，写成 `[文字](网址)` 更稳

## 标题

正文里的标题从二级开始：

```markdown
## 小标题
### 更小的标题
```

文章大标题写在 frontmatter 的 `title` 里，不要在正文再写一个 `# 标题`。

## 图片

图片文件放到 `public/images/` 下，引用时写 `/images/...`：

```markdown
![海边的下午](/images/posts/sea.jpg)
```

- `![ ]` 里是**图注**，会显示在图片下面
- 图片单独占一行，才会变成带图注的图；不要和文字挤在同一行
- 可选在引号里加备用说明：

```markdown
![海边的下午](/images/posts/sea.jpg "X-T5 · 33mm · f/2 · 1/500s")
```

- 引号里的内容不是图注，只在没有 EXIF 时做备用信息
- 封面不写在正文里，写在 frontmatter 的 `cover`：

```yaml
cover: /images/covers/your-cover.jpg
```

建议尺寸：封面 1600×1000 左右；正文图长边 1600px；上传前压一下，仓库会小很多。

## 注释和引用

用引用块当注释/旁白：

```markdown
> 注：这是一条注释。
```

页面会显示成左边一条竖线的引用样式。行内小注可以写：

```markdown
*注：这是一条行内小注。*
```

目前不支持 `[^1]` 这种脚注语法，注释统一用引用块或斜体小注。

## 列表

```markdown
- 第一项
- 第二项

1. 第一步
2. 第二步
```

## 表格

```markdown
| 项目 | 内容 |
| --- | --- |
| 相机 | Fujifilm X-T5 |
| 镜头 | XF 33mm F1.4 |
```

## 代码块

````markdown
```js
const hello = "world";
```
````

行内代码用单个反引号：`` `code` ``。

## 分隔线

单独一行写三个短横线：

```markdown
---
```

## 评测（老古董）

标题、日期、正文和普通文章一样，只把 `type` 改成 `review`：

```yaml
---
title: 型号：一句话结论
date: 2026-11-16
type: review
category: 器材
tags: [器材]
summary: 一句话摘要。
verdict: 一句话结论。
gear:
  kind: 镜头
  brand: 品牌
  model: 型号
  mount: 卡口
  price: 5299
  score: 8.8
  duration: 6 个月
  pros:
    - 优点一
    - 优点二
  cons:
    - 缺点一
  specs:
    焦段: 33mm
    重量: 360g
---
```

`verdict` 和 `gear` 都可以不写；只写 `type: review` 也会归到「老古董」。完整示例见 `templates/review.md`。

## frontmatter 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 文章标题 |
| `date` | 是 | `YYYY-MM-DD` |
| `type` | 否 | 默认 `essay`；评测写 `review` |
| `category` | 否 | 分类，显示在列表和文章顶部 |
| `tags` | 否 | 标签数组，如 `[随笔, 生活]` |
| `cover` | 否 | 封面图路径 |
| `summary` | 否 | 一句话摘要 |
| `draft` | 否 | `true` 时不生成文章 |

YAML 的冒号要用**半角冒号加空格**：`title: 标题`。值里如果有半角冒号，用引号包起来。

## 发布前检查

- 开头和结尾各有 `---`
- frontmatter 后面空一行再写正文
- 图片文件确实放在 `public/images/` 下
- 不想公开就先写 `draft: true`
- 保存后 watch 会自动重建，刷新页面即可
